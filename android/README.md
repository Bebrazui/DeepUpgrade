# DeepUpgrade Android App

Нативное Android-приложение для DeepSeek с предустановленным агентским ядром OpenCode (DeepUpgrade).

## Архитектура и возможности:
1. **WebView с аппаратным ускорением (`hardwareAccelerated="true"`)**:
   - Плавный 120Hz скролл без подергиваний и фризов.
2. **Агрессивное кэширование**:
   - `DOMStorage`, `IndexedDB`, `DatabaseEnabled` и `LOAD_DEFAULT` обеспечивают мгновенное открытие диалогов без повторной выкачки интерфейса по сети.
3. **Нативный темный стиль**:
   - Статус-бар и панель навигации Android окрашены в `#141416` (фирменный цвет DeepSeek), скрыт системный заголовок (`NoActionBar`).
4. **Внедрение расширения DeepUpgrade**:
   - Скрипты (`content.js`) и стили (`injected.css`) хранятся в `assets` и инжектируются в WebView при загрузке страницы.
   - Поддерживаются все инструменты: кнопка переключения **Agent**, **OpenCode виджеты с Git Diff**, **VFS**, **Python**, **Скиллы**.
5. **Маскировка под мобильный Chrome**:
   - `User-Agent` очищен от метки `; wv`, чтобы DeepSeek не блокировал браузер как WebView и не требовал капчу.
6. **Нативная обработка кнопки «Назад»**:
   - Системный жест / кнопка «Назад» возвращает по истории чатов внутри WebView, а не выбрасывает из приложения.

## Как собрать APK:
1. Откройте папку `C:\DeepUpgrade\android` в **Android Studio**.
2. Дождитесь Gradle Sync.
3. Нажмите **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** или запустите прямо на смартфоне через USB / Wi-Fi Debugging.
